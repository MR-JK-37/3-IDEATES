Open `dashboard_preview.html` in a web browser to see a static preview of the React Native `DashboardScreen.tsx`.

Usage:

```bash
# From project root
xdg-open desktop/preview/dashboard_preview.html    # Linux
open desktop/preview/dashboard_preview.html        # macOS
start desktop\preview\dashboard_preview.html     # Windows (Git Bash/PowerShell may differ)
```

Notes:
- This is a static HTML/CSS/JS mock using sample threat data.
- Replace the `mockThreats` array in the HTML to preview different scenarios.
- For live preview in app, run the React Native Metro bundler and use a simulator or device.
